### 1. C PROGRAMMING (60 MINUTES)
**Topic: Arrays**

Revise:
- Array traversal
- Largest and smallest element
- Second-largest distinct element

- Finding unique elements

Practice Programs:

2. Count how many times each element occurs.
3. Print only the elements that appear once.

**Interview Practice:**
- Explain the logic before writing the code.
- Handle duplicate elements correctly.
- Explain why your solution works.

### 2. APTITUDE (60 MINUTES)
**Topic: Time and Work**

Learn:
- Work and efficiency
- One person's work in one day
- Combined work
- Work done by different people
- Work and wages
- Pipes and cisterns

Important Formulas:

One day's work = 1 / Total days

Combined work = 1/A + 1/B

Time taken together = 1 / (1/A + 1/B)

Efficiency = Work / Time

Practice Questions:
1. A completes a job in 12 days and B in 18 days. Find their combined time.
2. A and B complete a job in 10 days. A alone takes 15 days. How long does B take?
3. A is twice as efficient as B. If B takes 20 days, how long does A take?
