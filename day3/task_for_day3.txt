# 1. C PROGRAMMING – ARRAYS
Duration: 60–75 minutes

### Problem 1: Merge Two Sorted Arrays
Merge two sorted arrays into one sorted array without using built-in sorting functions.

### Problem 2: Check Overlapping Ranges
Write a C program to check whether two numeric ranges overlap.

### Problem 3: Repeat Array Elements
Write a C program to repeat array elements to construct a new array.

### Problem 4: Forward and Backward Patterns
Generate arrays using forward and backward number patterns.

### Problem 5: Average Based on Divisibility
Find the average of array elements satisfying given divisibility conditions.

Target:
- Solve all 5 programs.
- Understand the logic.
- Test different inputs.
- Handle edge cases.
